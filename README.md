# 🌷 Aou × Boom — A Little Universe

A soft, aesthetic fan-made website celebrating **Aou Thanaboon and Boom Tharatorn**. Designed with a warm light theme, elegant typography, and a delicate combination of cream, dusty rose, and sage green.

This project brings the two artists into the spotlight through a beautiful landing page, individual profile sections, a photo gallery, and a heartfelt fan letter. ♡

## ✨ Features

- 🎨 **Aesthetic Light Theme** — Soft colours, warm backgrounds, and elegant typography.
- 🌟 **Hero Section** — A welcoming introduction with an artistic photo collage.
- 🤍 **Individual Profiles** — Dedicated sections celebrating Aou and Boom.
- 📸 **Photo Gallery** — A stylish gallery for favourite pictures and memories.
- 💌 **Fan Letter** — A heartfelt appreciation section.
- ✨ **Smooth Animations** — Subtle reveal effects while scrolling.
- 📱 **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- 🧭 **Interactive Navigation** — Smooth scrolling and a mobile-friendly menu.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts — Playfair Display and DM Sans

## 🚀 Run Locally

1. Download or clone this repository.
2. Make sure the main HTML file is named `index.html`.
3. Add your chosen images to the same folder as `index.html`.
4. Open `index.html` in your browser.

## 🌐 Deploy with GitHub Pages

1. Upload `index.html`, `README.md`, and your permitted image files to your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish your website.
